## كيفية الاختبار

### اختبار 1: إضافة حساب مع رقم هاتف
```
1. افتح التطبيق
2. اذهب إلى "الحسابات"
3. اضغط على "+" لإضافة حساب جديد
4. أدخل:
   - الاسم: "أحمد محمد"
   - الهاتف: "0501234567"
   - الرصيد: 1000
5. اضغط "إضافة"

النتيجة المتوقعة:
✅ يتم إنشاء الحساب
✅ يتم إضافة العميل تلقائياً
✅ تظهر رسالة في Console:
   🔍 جارِ التحقق من وجود العميل: "أحمد محمد" (0501234567)
   ➕ العميل غير موجود - جارِ الإضافة...
   ✅ تم إضافة العميل "أحمد محمد" بنجاح إلى قاعدة البيانات
```

### اختبار 2: إضافة حساب بدون رقم هاتف
```
1. اذهب إلى "الحسابات"
2. اضغط على "+" لإضافة حساب جديد
3. أدخل:
   - الاسم: "شركة xyz"
   - الهاتف: (اتركه فارغاً)
   - الرصيد: 5000
4. اضغط "إضافة"

النتيجة المتوقعة:
✅ يتم إنشاء الحساب
✅ يتم إضافة العميل بدون هاتف
✅ تظهر رسالة في Console:
   🔍 جارِ التحقق من وجود العميل: "شركة xyz" ()
   ➕ العميل غير موجود - جارِ الإضافة...
   ✅ تم إضافة العميل "شركة xyz" بنجاح إلى قاعدة البيانات
```

### اختبار 3: التحقق من وجود العميل
```
1. أضف حساب بنفس الاسم مرة أخرى
2. راقب Console

النتيجة المتوقعة:
✅ يتم إنشاء الحساب الجديد
✅ لا يتم تكرار العميل
✅ تظهر رسالة في Console:
   🔍 جارِ التحقق من وجود العميل: "أحمد محمد" (0501234567)
   ✅ العميل موجود مسبقاً في قاعدة البيانات
```

### اختبار 4: عرض العملاء
```
1. اذهب إلى "العملاء" من القائمة الرئيسية
2. تحقق من وجود العملاء المضافين

النتيجة المتوقعة:
✅ يظهر جميع العملاء المضافين
✅ البيانات كاملة (الاسم، الهاتف إن وجد)
```

## مراقبة Console

عند إضافة حساب جديد، يجب أن ترى إحدى الرسائل التالية:

### حالة النجاح:
```
🔍 جارِ التحقق من وجود العميل: "الاسم" (الهاتف)
➕ العميل غير موجود - جارِ الإضافة...
✅ تم إضافة العميل "الاسم" بنجاح إلى قاعدة البيانات
```

### حالة التكرار:
```
🔍 جارِ التحقق من وجود العميل: "الاسم" (الهاتف)
✅ العميل موجود مسبقاً في قاعدة البيانات
```

### حالة الخطأ:
```
❌ خطأ في إضافة العميل: [تفاصيل الخطأ]
```

## حل المشاكل

### المشكلة: العميل لا يظهر في قائمة العملاء

**الحلول:**
1. تحقق من Console messages
2. تأكد من أن الاسم ليس فارغاً
3. تحقق من أن قاعدة البيانات تم تهيئتها بشكل صحيح
4. أعد تشغيل التطبيق

### المشكلة: رسالة خطأ عند الإضافة

**الحلول:**
1. اقرأ رسالة الخطأ في Console
2. تأكد من أن جدول clients موجود
3. جرب حذف التطبيق وإعادة تثبيته (لإنشاء قاعدة البيانات من جديد)
