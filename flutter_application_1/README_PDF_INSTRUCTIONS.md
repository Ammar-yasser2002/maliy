README - تعليمات توليد إشعار PDF (عربي RTL)
=============================================

ما تمّ إضافته:
- كود مولّد PDF بالعربية: `lib/pdf/reminder_pdf.dart`
- صفحة تجربة سريعة: يمكن الوصول إليها عبر الراوت `/pdf_demo`، مضافة في `lib/mini_main.dart`
- تم إضافة الحزم: `pdf`, `printing`, `intl`, `path_provider` إلى `pubspec.yaml`

مهم - إضافة خط عربي:
- ضع ملف خط TTF يدعم العربية داخل المشروع في: `assets/fonts/arabic_font.ttf`.
  - مثال: يمكنك تحميل خط مثل "Tajawal" أو "Noto Naskh Arabic" من Google Fonts ووضعه بهذا المسار مع إعادة تسمية الملف إلى `arabic_font.ttf`.

تشغيل المشروع:
1. افتح التيرمينال في المسار `flutter_application_1`.
2. شغّل:

```powershell
flutter pub get
flutter run
```

اختبار مولد PDF:
1. بعد تشغيل التطبيق، انتقل إلى الراوت `/pdf_demo` (يمكن فتحه يدوياً أو إضافة زر في الواجهة).
2. املأ الحقول أو احتفظ بالقيم الافتراضية.
3. اضغط "توليد ومشاركة PDF" وستظهر لك نافذة المشاركة لحفظ أو إرسال الملف.

ملاحظات وقيود:
- يجب أن يتوفر خط عربي صالح في `assets/fonts/arabic_font.ttf` ليظهر النص العربي بشكل صحيح في PDF.
- الكود لا ينفّذ أي حوالات أو تحويلات؛ النظام يولّد إشعارات تذكير فقط.
- إذا ظهر خطأ بشأن الحزم بعد التعديل، شغّل `flutter pub get` ثم أعد تشغيل التطبيق.

أرشدني إن أردت أن أدرج ملف ttf مناسب في المشروع (أستطيع إضافته لو وفّرت الملف)، أو أدمج ميزة حفظ تلقائي داخل مجلد الجهاز.
